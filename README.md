# KantorKu (MVP)

Aplikasi kantor Android orisinal: pengelola berkas, penampil PDF, editor teks, lembar kerja sederhana.

## Cara mendapat APK
1. Buat repositori GitHub baru, unggah seluruh isi folder ini (termasuk `.github/`).
2. Buka tab **Actions** > workflow **Build APK** > tunggu selesai (atau klik *Run workflow*).
3. Unduh artifact `kantorku-debug-apk`, ekstrak, pasang `app-debug.apk` di HP (izinkan "install dari sumber tidak dikenal").
4. Jika build gagal, salin log error dari langkah yang merah dan kirim ke Claude.

Build ini belum pernah dijalankan oleh penulisnya; kemungkinan perlu perbaikan.
